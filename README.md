# C++ Contact Book CLI

A simple command-line address book management system written in C++.

## Features

- Add new contact
- Delete contact by name, phone, or email
- Search contact
- Modify contact (address, phone, or email)
- Display all contacts
- Sort contacts by name, address, phone, or email

## Build and Run

Using `g++`:

```bash
g++ -std=c++17 -o contact-book src/main.cpp
./contact-book
